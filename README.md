
# NLP From Scratch

A hands-on journey from Python programming to NLP and deep learning.

## Goals

- Build independent programming and debugging skills.
- Learn Python, NumPy, PyTorch, and NLP fundamentals.
- Implement core algorithms without relying on AI-generated solutions.
- Progress toward understanding and reproducing deep learning research.

## Project Structure

- `src/textlab/` — Python source code
- `tests/` — Tests
- `data/` — Sample datasets

## Requirements

- Python 3.11+

## Run

In PowerShell, from the project root:

```powershell
$env:PYTHONPATH = "src"
python -m textlab
```

## Learning Principles

1. Understand the problem before writing code.
2. Implement core logic independently.
3. Test and debug before requesting solutions.
4. Repair knowledge gaps before adding complexity.
