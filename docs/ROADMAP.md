# NLP From Scratch｜长期学习路线 V1.0

> 定位：项目是训练场，**独立解决问题的能力**才是成果。
> 最终方向：为复旦邱锡鹏团队相关的 NLP / LLM / AI 系统研究打基础；不把「完成项目」或「调用框架成功」误当成掌握。
> 学习场景：办公室在工作允许的空闲时间推进，允许中断；晚上优先考研。不按固定日期赶进度。

## 1. 两条始终并行的主线

- **编程主线**：读懂需求 → 独立设计 → 手写核心实现 → 调试 → 测试 → 复盘。允许查语法、API、文档；不让 AI 代写核心逻辑。
- **知识主线**：Python → 数组与必要数学 → 机器学习 → PyTorch → Transformer / LLM → 实验与论文。只在实际需要时补前置知识，但核心知识必须扎实。

## 2. 阶段路线（通关制，不按日期推进）

| 阶段 | 需要获得的能力 | 持续演进的练习载体 | 通关证据 |
| --- | --- | --- | --- |
| **0 环境与版本控制** ✅ | Python、venv、PyCharm、Git、运行与提交 | `nlp-from-scratch` 仓库 | 本地运行通过、首次 Commit、远程同步通过 |
| **1 Python 基础** ← 当前 | 函数、字符串、列表/字典、文件、模块、异常、调试与基本测试 | **TextLab v1**：文本读取、清洗、词频、Top-K | 脱离教程独立实现一个小功能，并用边界用例验证 |
| **2 数据表示与机器学习基础** | NumPy、形状与广播、必要的线代/概率、训练集与验证集、损失与梯度 | **TextLab v2**：词表、词袋/向量表示、简单文本分类基线 | 能解释每一步的数据形状和评价指标；能手写一个核心计算并检验 |
| **3 PyTorch 与神经网络** | Tensor、autograd、MLP、Embedding、优化器、训练循环 | **TextLab v3**：手写训练循环并训练小型文本分类模型 | 从空文件搭起可复现训练流程；解释参数如何更新、为什么收敛或失败 |
| **4 Transformer 基础** | Attention、Q/K/V、Mask、多头、残差、LayerNorm | **TextLab v4**：最小 Attention / Transformer；衔接 `llm-beginner` 任务 1 | 独立实现关键组件，通过数值/形状测试，解释设计与边界 |
| **5 小型语言模型** | Tokenization、序列建模、预训练、采样、基本评测 | **TextLab v5**：mini-GPT；衔接 `llm-beginner` 任务 2 | 小语料训练与生成可重复；能解释 Loss、采样和至少一个对照实验 |
| **6 LLM 进阶与科研训练** | SFT/LoRA/DPO、RAG、Agent 等按研究兴趣选择；论文、基线、消融与错误分析 | 优先使用 `llm-beginner` 后续任务与 NNDL 实践，形成独立实验 | 不只跑通：能提出假设、设计对照、复现结果并写清局限 |

**选材原则**：以邱锡鹏团队公开的 `llm-beginner` 编程任务作为中长期实战目标；《神经网络与深度学习》及 `nndl-practice` 用来补理论与核对实现。**现在不直接啃大仓库**，先建立进入其任务 1 所需的能力。后续研究兴趣可再偏向 LLM 算法、智能体或 AI Infra，不急着同时铺开。

## 3. 推进节奏：快反馈，但不虚假通关

- 每个阶段都要有**可运行、可解释、可测试的小成果**；优先复用 `textlab`，不要每遇到难题就重启新项目。
- 每次只设**一个主要任务、一个主要知识缺口**。基础熟悉则加速通过；不会的地方认真补，绝不按“上了几天课”判定掌握。
- 模仿能运行 ≠ 掌握；必须至少有一次**关掉参考资料的独立实现**，再做变化输入或边界测试。
- 新增复杂度时优先换一个有挑战的小条件，而不是一次叠加五个新框架。

## 4. 知识断层保护协议（防止第 15～20 天中断）

1. 卡住时先写出：**目标、输入输出、已知部分、第一处不会的地方**。
2. 分辨是 **API/语法、基础概念、算法设计，还是工程组织**。
3. API 直接查；概念断层则临时退出项目，做**一个最小知识实验**，完成后返回原功能。
4. 如果连续**两个有效学习时段**仍无进展，停止硬顶，向导师请求定位与分层提示；必要时缩小需求，**不换项目**。
5. 如果需要同时补多个陌生前置知识，说明阶段跨度过大：降低当前任务复杂度或在路线中插入小关卡。

## 5. 与 AI 合作的边界

- **自己做**：需求拆解、架构初稿、核心算法、关键代码、首轮调试和核心测试。
- **AI 可以做**：解释语法/API、指出最早错误、分层提示、代码审查、非核心环境脚手架。
- 完整参考解仅在我明确请求、或反复卡住需要核对后提供；看过参考实现的功能，需要隔一段时间独立复写或做变式。

## 6. 进度维护（只在阶段验收或路线变化时更新）

- 当前阶段：**阶段 1｜Python 基础（LEARNING）**
- 已验证：Day 0 环境、运行、Git 首次提交及 GitHub 同步。
- 当前任务：从 Python 零基础开始，独立搭建最小文本处理能力。
- 最近的知识断层：待实际编码暴露后记录。
- 下一个里程碑：不看完整答案，独立完成并测试 TextLab v1 的基础功能。

知识状态使用：`NEW → LEARNING → REVIEW → MASTERED`。没有独立实现与验证的证据，不标记 MASTERED。

## 7. 不做什么

暂不追逐复杂开源仓库、分布式训练、生产级 LLM、Quant 支线、过度工程化、无目标的长课刷完。它们并非永远不学，而是**当前收益不足、容易打断主线**。
